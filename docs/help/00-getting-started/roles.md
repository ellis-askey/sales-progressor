# Roles — Directors and Negotiators

There are two roles for agency staff: **director** and **negotiator**. Both use the same part of the platform (the agent portal at `/agent/*`), but directors have additional management capabilities.

## Director

The director is the top of the agency hierarchy within the platform. There is typically one director per branch, though a larger firm may have multiple.

**Directors can:**
- See all files in the branch (unless restricted by firm name)
- Add and remove negotiators
- Control whether individual negotiators can view all files or only their own
- Manage sending email addresses
- Delete the agency account

**Directors cannot:**
- See files belonging to other branches in the same firm (if the firm has multiple branches, each branch is scoped separately)

## Negotiator

Negotiators handle day-to-day sales progression work.

**Negotiators can:**
- Create new property files
- Mark milestones complete and not-required
- Generate and send chase emails
- Add notes and manual tasks
- Send portal links to clients
- Update their own profile

**Negotiators may or may not be able to:**
- See all files in the branch — this depends on the "Can view all files" setting, which the director controls

If a negotiator can only see their own files, they will not see files created by their director or other negotiators.

## Checking your role

Your role is shown on the Settings page. If you see a "Team" section with the ability to add negotiators, you are a director.
