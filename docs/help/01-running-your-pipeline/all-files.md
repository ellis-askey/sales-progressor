# All Files — Your Full Transaction List

The All Files view (`/agent/dashboard`) shows every transaction you have access to. By default it shows active files; use the filters to find anything.

## Filters

The filter bar lets you narrow by:
- **Status** — active, exchanged, completed, withdrawn, fallen through
- **Service type** — self-managed or with progressor
- **Assigned progressor** — if you use the outsourced service and have multiple progressors assigned

## What each row shows

Each row in the file list shows:
- Property address
- Buyer and seller names
- Current progress percentage (weighted milestone completion)
- Status
- Days since last activity

Click any row to open that property file.

## Sorting

Files can be sorted by address, progress, or last activity. The default order is by last activity — most recently updated first.
