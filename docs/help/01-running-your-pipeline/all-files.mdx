# All Files

All Files shows every transaction you have access to. By default it shows active files; use the filters to find anything else.

## Filters

| Filter | Options |
|---|---|
| **Status** | Active, exchanged, completed, withdrawn, fallen through |
| **Service type** | Self-managed or with progressor |
| **Assigned progressor** | If you use the outsourced service with multiple progressors |

## What each row shows

- Property address
- Buyer and seller names
- Current progress percentage (weighted milestone completion)
- Status
- Days since last activity

Click any row to open that property file.

## Sorting

Files can be sorted by address, progress, or last activity. The default is by last activity — most recently updated first.
