# Analytics

The Analytics page shows pipeline performance across your agency. Use the period tabs at the top to switch between This week, This month, This year, and All time.

Directors can also filter by team member using the user selector, and export data to CSV.

## KPI counts

The counts card shows three figures for the selected period:

| Metric | What it measures |
|---|---|
| **Submitted** | Files created in the period |
| **Exchanged** | Files that exchanged in the period — with exchange rate shown as a percentage of submitted |
| **Completed** | Files that completed in the period — with completion rate shown as a percentage of exchanged |

Each figure includes a sparkline showing the trend across the previous 12 months, and a delta pill comparing it to the same period prior (for week, month, and year views).

## Conversion funnel and speed to exchange

The conversion funnel shows submitted → exchanged → completed as a visual drop-off chart for the selected period.

The speed to exchange card shows average days from instruction to exchange for files in the period:

| Rating | Average days |
|---|---|
| **Fast** | Under 70 days |
| **Typical** | 70–100 days |
| **Slow** | Over 100 days |

## Value and fees

**Pipeline value and value exchanged** — total purchase prices for files submitted in the period, and the subset of those that have exchanged. A delta shows the change versus the prior period.

**Fee pipeline, locked in, and average fee** — total agent fees recorded (inclusive of VAT where set), fees from exchanged files only, and average fee per file. Files missing a fee entry are flagged and linked to the missing fees section below.

**Fee forecast** — estimated fees from files expected to exchange in the current calendar month, based on expected exchange dates set on each file.

## Charts

Two charts appear side by side:
- **Files submitted** — bar chart by day (week view) or by month (month, year, and all-time views)
- **Monthly activity** — combined bar chart showing files created and files exchanged across the last 12 months

## Solicitor exchange performance

If files have solicitor firms recorded, a table shows each firm's average days from instruction to exchange, ranked fastest first, with a Fast/Typical/Slow badge.

## Files missing a fee

Active files with no agent fee recorded are listed here. Fee pipeline and forecast figures exclude these files until a fee is set.

## Files at risk

A panel flagging files that may need attention — files with no recent activity or where progress has stalled.

## Team leaderboard

Directors see a leaderboard when the team has more than one member and no user filter is applied. It shows each member's submitted count, exchanges, conversion rate, pipeline value, average fee, and locked-in fees for the selected period.
