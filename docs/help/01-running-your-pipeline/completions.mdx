# Completions

The Completions page shows files that have exchanged and are heading to completion. Once a file exchanges, it moves here and stays until completion is recorded.

The header shows the total count, total fees (where set), and total sale value across all files in view.

## How files are grouped

Files are grouped by completion date proximity:

| Group | Condition |
|---|---|
| **Overdue** | Completion date is in the past |
| **Completing this week** | Completion date is within the next 7 days |
| **Completing next week** | Completion date is 7–14 days away |
| **Later** | Completion date is more than 14 days away |
| **No completion date set** | No date has been entered on the file |

Setting the completion date when exchange happens keeps the groupings accurate.

## What to do once a file exchanges

1. Mark **VM19** (contracts exchanged — seller) and **PM26** (contracts exchanged — buyer) complete
2. Enter the completion date on the file
3. On the day of completion, mark **VM20** (sale completed) and **PM27** (purchase completed) complete
4. Change the file status to Completed
