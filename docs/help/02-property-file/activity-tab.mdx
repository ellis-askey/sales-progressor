# Activity Tab

The Activity tab is the full chronological history of a file — every meaningful action, most recent first. It is written automatically; no manual maintenance is needed.

## What appears in the activity log

- Milestones marked complete — who marked it and when
- Milestones unmarked — if a completion was reversed
- Notes added by you or a colleague
- Chase emails sent — recipient, milestone, and timestamp
- Portal links sent to clients
- Manual tasks created and completed
- Status changes — for example, file moved to Exchanged or Withdrawn
- Contact details updated

## Adding a note

Click **Add note** to write a free-text note. Notes are only visible to your agency — they are not shown to clients in the portal. Use notes to record phone calls, explain why a milestone was marked in a particular way, or flag something for a colleague.

## Filtering the timeline

Use the filter buttons at the top of the timeline to show only certain types of entries: milestones, notes, emails, or status changes.
