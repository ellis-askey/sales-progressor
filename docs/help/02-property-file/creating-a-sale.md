# Creating a New Sale

Click **New sale** in the top right of the Hub to open the new sale form.

## Required information

### Property details

- **Address** — the full property address. This is used everywhere the file is referenced: the Hub, all-files list, portal, reports.
- **Sale price** — the agreed sale price. Used in the pipeline value stat on the Hub.
- **Property type** — freehold or leasehold. This determines which milestones apply automatically (see below).
- **Expected exchange date** — optional but recommended. Used in the exchange forecast on the Hub.

### Vendor (seller) contacts

Add the seller's name and email address. You can add more than one contact (e.g. two owners on a joint sale). Each contact gets their own portal link.

You can also add the seller's solicitor firm name and the solicitor's name and email.

### Purchaser (buyer) contacts

Same as vendor: buyer name(s), email, and their solicitor details.

You can also note whether the buyer is purchasing with a **mortgage** or **cash**. This determines which purchaser milestones apply automatically.

## How property type and purchase method affect milestones

The answers you give here change which milestones are active from the start:

| Answer | Effect |
|---|---|
| **Freehold** | VM8 (management pack requested) and VM9 (management pack received) are marked Not Required; PM12 (management pack received — buyer) is also Not Required. |
| **Leasehold** | VM8, VM9, and PM12 remain active — you'll need to obtain a management pack from the freeholder or managing agent. |
| **Cash buyer** | PM5 (mortgage application submitted), PM6 (lender valuation booked), and PM11 (mortgage offer received) are marked Not Required. |
| **Mortgage buyer** | PM5, PM6, and PM11 remain active. |

These are applied automatically when the file is created. You can adjust them later from the Milestones tab if circumstances change.

## After creating the file

Once the file is saved you land on the **Overview tab** of that property file. From here:

1. Send portal links to the buyer and seller
2. Review the milestone list and confirm the starting state is correct
3. Mark VM1 and PM1 as complete if the sellers and buyers have already instructed their solicitors
