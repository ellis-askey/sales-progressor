# Creating a New Sale

Click **New sale** in the top right of the Hub to open the new sale form.

## Required information

### Property details

- **Address** — the full property address. Used everywhere the file is referenced: the Hub, all-files list, portal, reports. For example: 22 Birchwood Lane, Cheltenham.
- **Sale price** — the agreed sale price. Used in the pipeline value stat on the Hub.
- **Property type** — freehold or leasehold. This determines which milestones apply automatically.
- **Expected exchange date** — optional but recommended. Used in the exchange forecast on the Hub.

### Vendor (seller) contacts

Add the seller's name and email address. More than one contact can be added — for example, two owners on a joint sale. Each contact gets their own portal link.

You can also add the seller's solicitor firm name and the solicitor's contact details.

### Purchaser (buyer) contacts

Same as vendor: buyer name(s), email, and their solicitor details.

Noting whether the buyer is purchasing with a **mortgage** or **cash** determines which purchaser milestones apply automatically.

## How property type and purchase method affect milestones

| Answer | Effect |
|---|---|
| **Freehold** | VM8 and VM9 (management pack milestones) and PM12 are set to Not Required |
| **Leasehold** | VM8, VM9, and PM12 remain active |
| **Cash buyer** | PM5 (mortgage application), PM6 (lender valuation), and PM11 (mortgage offer) are set to Not Required |
| **Mortgage buyer** | PM5, PM6, and PM11 remain active |

These are applied automatically at file creation. They can be adjusted from the Milestones tab if circumstances change.

## After creating the file

Saving the file opens the **Overview tab**. From there:

1. Send portal links to the buyer and seller
2. Review the milestone list and confirm the starting state is correct
3. Mark VM1 and PM1 complete if solicitors have already been instructed
