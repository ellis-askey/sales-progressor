# Overview Tab

The Overview tab is the first tab you see when opening a property file. It gives a summary of the file without requiring you to scroll through every milestone.

## What's on the Overview tab

### Property header

At the top: property address, sale price, current status badge, and overall progress percentage. The progress bar reflects weighted milestone completion across both the vendor and purchaser sides.

### Contacts card

Shows the buyer and seller contacts — names, email addresses, and phone numbers if added. Each contact has a portal link button. Click it to copy or send that client's portal link.

The card also shows when a client last visited their portal, if they have opened it.

### Solicitors card

Shows vendor and purchaser solicitor details. Click to expand and edit if details change during the transaction.

### Quick milestone summary

A condensed count of milestones complete, in progress, and not yet started on each side. Click "View all milestones" to go to the Milestones tab.

### Active reminders widget

Shows the top active reminders — chaseable items that are due, overdue, or escalated. Clicking a reminder opens the Reminders tab.

### Recent activity widget

The last few entries from the activity log. Clicking "View all" opens the Activity tab.

## Editing property details

Click the edit icon next to the property address or sale price to update them. The expected exchange date can also be updated from the Overview tab.
