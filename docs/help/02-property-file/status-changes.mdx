# Changing File Status

Every file has a status reflecting where it stands in the sales process. The status is shown as a badge at the top of the property file and in the All Files list.

## Available statuses

| Status | Meaning |
|---|---|
| **Active** | The sale is in progression. This is the default from file creation. |
| **Exchanged** | Contracts have been exchanged — both VM19 and PM26 should be marked complete. |
| **Completed** | The sale has completed — both VM20 and PM27 should be marked complete. |
| **Withdrawn** | The file has been withdrawn or put on hold. |
| **Fallen through** | The sale collapsed entirely. |

## How to change status

Open the property file. On the Overview tab, click the status badge. A dropdown shows the available next states. Select the new status and confirm.

Marking VM20 (sale completed — seller) or PM27 (purchase completed — buyer) complete will prompt you to update the file status automatically.

## Effect on the Hub

Exchanged and Completed files drop off the Active Files count on the Hub. Withdrawn and Fallen through files also leave the active pipeline. All non-active files remain visible in All Files with the appropriate status filter applied.

## Reopening a file

If a sale falls through and then resurrects — for example, the buyer is replaced — change the status back to Active. All milestones, notes, and history are preserved.
