# To-Do Tab

The To-Do tab holds manual tasks — things that don't fit neatly into a milestone but still need tracking. Examples: "Call seller to confirm keys arrangement", "Ask buyer's solicitor for updated ID documents", "Chase managing agent for estimated service charge".

## Difference from reminders

Reminders are generated automatically by the system based on milestone progress. To-do items are created manually by you or a colleague. They don't affect the milestone progress percentage, but they're useful for capturing actions that fall outside the structured milestone workflow.

## Creating a to-do item

Click **Add task** in the To-Do tab. Enter:
- **Task description** — what needs to be done
- **Due date** (optional) — when this should be completed by
- **Assigned to** (optional, directors only) — which team member should handle it

## Completing a task

Click the checkbox next to a task to mark it done. Completed tasks move to a separate completed list at the bottom of the tab and are recorded in the activity log.

## Editing and deleting tasks

Click any open task to edit the description, due date, or assignee. To delete a task entirely, open it and click the delete button.
