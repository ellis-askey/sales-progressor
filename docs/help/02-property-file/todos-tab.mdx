# To-Do Tab

The To-Do tab holds manual tasks — things that do not fit into a milestone but still need tracking.

Examples: "Call James Patel to confirm key collection arrangements", "Ask buyer's solicitor for updated ID documents", "Chase managing agent for estimated service charge".

## Difference from reminders

Reminders are generated automatically from milestone progress. To-do items are created manually. They do not affect the progress percentage, but they capture actions that fall outside the structured milestone workflow.

## Creating a to-do item

Click **Add task**. Enter:
- **Task description** — what needs to be done
- **Due date** (optional) — when it should be completed by
- **Assigned to** (optional, directors only) — which team member should handle it

## Completing a task

Click the checkbox next to a task to mark it done. Completed tasks move to a separate list at the bottom of the tab and are recorded in the activity log.

## Editing and deleting tasks

Click any open task to edit its description, due date, or assignee. To delete a task, open it and click the delete button.
