# Exchange Gates

Before contracts can be exchanged, both sides must confirm they are ready. In Sales Progressor, this is enforced through two milestones:

- **VM18** — Seller's solicitor ready to exchange
- **PM25** — Buyer's solicitor ready to exchange

Both must be marked Complete before exchange can happen. If only one side is ready, the file sits in a waiting state — marked ready on one side, still pending on the other.

## Why there are two gates

Exchange in a residential sale requires simultaneous confirmation from both solicitors. The seller's side must have: signed contracts, all ID completed, all enquiries answered, and the seller's solicitor confirmed ready. The buyer's side must have: signed contracts, deposit held, all enquiries satisfied, mortgage offer in place (if applicable), and the buyer's solicitor confirmed ready.

The two gates track these two independent confirmations. Either can be achieved first — the order does not matter. Both must be Complete before the file moves to Exchanged.

## What triggers each gate becoming Available

**VM18** becomes Available when VM17 (signed contracts returned by seller) is marked Complete.

**PM25** becomes Available when PM24 (deposit transferred by buyer) is marked Complete.

Both gates have 2-day grace periods and 2-day repeat intervals — they are the most urgently chased milestones in the system.

## What happens after both gates are complete

Once VM18 and PM25 are both Complete, the file is flagged as "Exchanging soon" in the Hub pipeline stats. The next steps are:

1. Mark **VM19** (contracts exchanged — seller) and **PM26** (contracts exchanged — buyer) once exchange actually happens
2. Enter the completion date on the file
3. Mark **VM20** (sale completed) and **PM27** (purchase completed) on the day of completion
4. Update the file status to Exchanged, then Completed
