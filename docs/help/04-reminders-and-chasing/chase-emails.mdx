# Generating Chase Emails

Chase emails are generated using AI and sent from within the file. The system knows which milestone is being chased, the property address, and the relevant contacts — so the draft is contextually accurate and ready to review before sending.

## Opening the chase drawer

From the **Reminders tab** of a file, click **Chase** next to an active reminder. The chase drawer opens as a slide-in panel.

You can also reach it from the **Reminders** page — clicking any reminder row takes you to the Reminders tab of that file.

## Choosing a channel and tone

**Channel** — choose between email and WhatsApp.

**Tone** — choose from six options:

| Tone | Typical chase number |
|---|---|
| Friendly | 1st chase |
| Professional | 2nd chase |
| Polite Yet Firm | 3rd chase |
| Chase Up | 4th chase |
| Urgent | 5th chase |
| Final Reminder | 6th chase |

The tone is pre-selected automatically based on how many times this milestone has already been chased. For example, if VM5 on 22 Birchwood Lane has been chased twice before, the drawer opens with "Polite Yet Firm" already selected. You can change it before generating.

## Generating and sending

1. Click **Generate**. The AI drafts a message based on the milestone, property address, and contacts.
2. Review the draft in the editable text area. Edit anything that needs adjusting.
3. Click **Send**. The message is sent and the chase is logged in the Activity tab.

## What address the email comes from

If you have a verified sending address set up in Settings, the email goes from your work address — for example, `olivia@hartwellestates.co.uk`. If not, it goes from a generic Sales Progressor address.

See [Verified sending addresses](../07-notifications/verified-sending-addresses).

## Rate limiting

To prevent accidental email flooding, the number of chase emails that can be sent within a given window is limited. If you hit the limit, the system tells you when you can try again.
