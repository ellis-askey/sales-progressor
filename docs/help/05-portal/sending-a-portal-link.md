# Sending a Portal Link

Each contact on a file has their own portal link. You can send it at any time after creating the file.

## Where to find the portal link

Open the property file and go to the **Overview tab**. The Contacts card shows each buyer and seller with a portal link button next to their name.

## Sending the link

Click the portal link button next to the client's name. You have two options:

**Copy link** — copies the portal URL to your clipboard so you can paste it into your own email, text message, or WhatsApp.

**Send by email** — sends an introductory email directly from the platform to the client's email address. The email explains what the portal is and includes the link. The email comes from your verified sending address if you have one set up.

## When to send the portal link

Send it as soon as the file is created and you've had the initial conversation with the client. Don't wait until there's lots of progress to show — clients appreciate being given access early, and it sets the expectation that they can check in themselves rather than having to call.

If you're sending it by email, make sure the client's email address on the file is correct before sending.

## Resending the link

There is no concept of the portal link expiring, so there is nothing to "resend" in the technical sense. If a client says they lost the email, copy the link from the Overview tab and share it again.

## Multiple contacts

If a property has two sellers (joint ownership), each gets their own portal link. The links are separate — each person's link only shows their view of the transaction. Send each link to the appropriate person.

## Checking if a client has viewed the portal

The Overview tab shows the last time each contact visited their portal. This is helpful if a client says they haven't received information — you can confirm whether they've opened the portal at all.
