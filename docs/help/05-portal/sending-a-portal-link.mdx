# Sending a Portal Link

Each contact on a file has their own portal link. It can be sent at any time after the file is created.

## Where to find the portal link

Open the property file and go to the **Overview tab**. The Contacts card shows each buyer and seller with a portal link button next to their name.

## Sending the link

Click the portal link button next to the client's name. Two options appear:

**Copy link** — copies the portal URL to your clipboard so you can paste it into your own email, text message, or WhatsApp.

**Send by email** — sends an introductory email directly to the client's email address. The email explains what the portal is and includes the link. It comes from your verified sending address if one is set up.

## When to send

Send it as soon as the file is created and you have had the initial conversation with the client. Do not wait until there is lots of progress to show — clients appreciate being given access early, and it sets the expectation that they can check in themselves rather than having to call.

Make sure the client's email address on the file is correct before sending by email.

## Resending the link

Portal links do not expire. If a client says they lost the email, copy the link from the Overview tab and share it again.

## Multiple contacts

If a property has two sellers (joint ownership), each gets their own portal link. The links are separate — each person's link shows only their view of the transaction. Send each link to the appropriate person.

## Checking if a client has viewed the portal

The Overview tab shows the last time each contact visited their portal. This is useful if a client says they have not received information — you can confirm whether they have opened the portal at all.
