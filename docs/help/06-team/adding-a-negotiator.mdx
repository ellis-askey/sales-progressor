# Adding a Negotiator

Directors can add negotiators from the Settings page.

## Steps

1. Go to **Settings** (cog icon in the sidebar).
2. Scroll to the **Team** section.
3. Click **Add negotiator**.
4. Enter the negotiator's full name, email address, and a temporary password.
5. Click **Create account**.

The negotiator can now log in with the email and temporary password you set. Ask them to change their password on first login via the Profile section in Settings.

## File visibility

By default, a new negotiator can only see files they created themselves. To allow them to see all files in the branch, toggle **Can view all files** in the Team section.

See [File visibility](file-visibility) for more detail.

## No account limit

There is no limit on the number of negotiator accounts you can add.

## Removing a negotiator

Find the negotiator in the Team section and click **Remove**. Their account is disabled immediately. Their files remain — removing a negotiator does not delete or change any of the files they worked on.
