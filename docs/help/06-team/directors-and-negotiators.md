# Directors and Negotiators

## The difference between the two roles

**Directors** are the account owners within an agency. They have full access to all files in their branch and manage the team — adding negotiators, controlling visibility, and handling account settings.

**Negotiators** do the day-to-day progression work. They can create files, work milestones, send chases, and manage client communication. They cannot add or remove colleagues or access team settings.

## What directors can do that negotiators cannot

| Action | Director | Negotiator |
|---|---|---|
| See all files in the branch | ✓ | Only if "can view all files" is enabled |
| Add a negotiator | ✓ | — |
| Remove a negotiator | ✓ | — |
| Control file visibility for a negotiator | ✓ | — |
| Verify a sending address | ✓ | ✓ |
| Delete the agency account | ✓ | — |
| Create and edit files | ✓ | ✓ |
| Mark milestones | ✓ | ✓ |
| Send chase emails | ✓ | ✓ |
| Send portal links | ✓ | ✓ |

## Multiple branches

If your firm has multiple branches (e.g. a group with several offices), each branch has its own director account. Files are scoped to the branch — a director in one branch does not see files from another branch.
