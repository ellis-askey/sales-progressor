# File Visibility

By default, negotiators can only see files they created themselves. This is the default for agencies where negotiators have their own client portfolios and should not see each other's files.

## Changing a negotiator's visibility

Directors can change a negotiator's visibility setting from the **Team** section in Settings:

1. Go to **Settings → Team**.
2. Find the negotiator in the list.
3. Toggle **Can view all files**.

When enabled, the negotiator can see all active files in the branch — not just their own.

## Visibility for directors

Directors always see all files in their branch. This cannot be restricted.

## Files created before a negotiator joined

If you enable "can view all files" for a negotiator, they gain access to all existing files in the branch — including files created before they joined.

## Who can see the Team section

Only directors see the Team section in Settings. Negotiators do not have access to team management or visibility settings.
