# Verified Sending Addresses

When a chase email or portal link email is sent, it needs to come from somewhere. By default it comes from a generic Sales Progressor address. Setting up a verified sending address makes outgoing emails appear as coming from your own work email.

## Why it matters

An email from `olivia@hartwellestates.co.uk` is more trusted by solicitors and clients than one from a generic platform address. It also keeps your professional brand consistent — the recipient sees it as coming directly from you.

## How to verify an address

1. Go to **Settings → Sending addresses**.
2. Click **Add address**.
3. Enter your work email address.
4. A verification email is sent to that address.
5. Click the confirmation link in that email.
6. The address is now verified and will be used for all outgoing emails.

## DNS records

To ensure emails pass spam checks reliably, your IT team or domain host may need to add DNS records. The Settings page shows the exact CNAME records that need to be added. The "Send instructions" option in the Sending addresses section can email the DNS details to your IT contact directly.

## Multiple addresses

If different negotiators each use their own email address, each person can verify their own sending address. Each user's outgoing emails then come from their own verified address.

## What happens if no verified address is set

Emails are still sent, but they come from a generic Sales Progressor address. All functionality works the same — only the displayed "From" address differs.
